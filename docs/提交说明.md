# 课程项目提交说明

主报告为 `reports/室内占用检测课程项目实验报告.docx`，包含数据质量、方法、实验设置、两个测试集与合并结果、特征对比、误差分析、环境响应、结论局限和混淆矩阵。报告未代填姓名、学号等个人信息，提交前可根据老师要求补充。

结果文件为 `outputs/complete/occupancy_predictions.csv`。共6种方法，每种覆盖12,417条测试记录，总计74,502条数据行。七列为 `source_file, source_row, date, occupancy_true, occupancy_pred, score, method`。

源码与数据保持原有相对路径。完整运行顺序及依赖见根目录README。划分清单在 `outputs/step01/split_manifest.json`，指标与参数在 `outputs/complete/metrics.csv`、`experiment.json`，独立核验记录为 `validation.json`。规则阈值与第一轮参数也保留在 `outputs/step02/`。

主要图表包括特征比较图、两个测试全时段与第二个日历日的连续图、状态切换环境变化图，同时提供PNG与SVG。原始输入放在 `data/`，实验输出放在 `outputs/`，报告放在 `reports/`，不将虚拟环境、缓存或文档渲染工具交给老师。

`deliverables/室内占用检测课程项目提交包.zip` 保持上述目录结构，并附带逐文件SHA-256清单。解压后可按README复现，不应只单独复制脚本到其他目录运行。

当前结论为课程数据范围内的结果。组合模型在合并测试上领先，但未被验证集排为第一；不能声称它是通过验证集选择的最终冠军。进入响应曲线只有1次合格事件，不能据此断言固定滞后时间。报告已说明这些限制。
